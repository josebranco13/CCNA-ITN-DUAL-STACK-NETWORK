# Project Evidence

This directory contains screenshots and command outputs that demonstrate that the network was configured and tested successfully.

The evidence is divided into four categories:

| Category | Description |
|:---------|:------------|
| [IPv4](ipv4/) | IPv4 addressing, interfaces, routing and connectivity |
| [IPv6](ipv6/) | IPv6 automatic configuration, routing and connectivity |
| [Network Services](services/) | DHCP, DNS and HTTP configuration and testing |
| [Troubleshooting](troubleshooting/) | Evidence of a network problem, diagnosis and correction |

The evidence was collected from the final Cisco Packet Tracer project.

The complete verification process is described in:

- [Network Verification](../docs/verification.md)
- [Network Troubleshooting](../docs/troubleshooting.md)

## Evidence Purpose

The purpose of this directory is to prove that the network was not only configured, but also tested.

The screenshots demonstrate:

- communication inside local networks;
- communication between different networks;
- communication between the headquarters and the remote branch;
- IPv4 connectivity;
- IPv6 connectivity;
- correct routing information;
- automatic IPv4 configuration through DHCP;
- DNS name resolution;
- access to the internal HTTP website;
- successful correction of an IPv6 communication problem.
